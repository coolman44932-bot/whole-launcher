Put Whole Launcher mods here.

- A mod is a folder with a manifest.ini (and tweaks, text patches or scripts) inside.
- You can also press "Add mod (.zip)..." in Whole Launcher and pick a downloaded .zip.
- FractureLoader-style mods (manifest.ini + camel/ folder) work here too.

Then tick the mods you want, set the order (lower in the list wins), press Install mods, then Play.
